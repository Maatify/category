# Maatify Engineering Standards - Agent Guidelines

هذا الملف مخصص كدليل للوكلاء (AI Agents) العاملين في مستودع `Maatify/php-engineering-standards`.

- **المراجع الإلزامية للتعاون ودورة الحياة:** يجب اتباع الإرشادات الواردة في المعيارين التاليين بشكل صارم، حيث يختص الأول بالأدوار والتنسيق والثاني بهيكل فروع Git وطلبات السحب:
  1. [`standards/ai/AI_COLLABORATION_WORKFLOW_AR.md`](standards/ai/AI_COLLABORATION_WORKFLOW_AR.md)
  2. [`standards/GITHUB_PHASE_STACK_WORKFLOW_AR.md`](standards/GITHUB_PHASE_STACK_WORKFLOW_AR.md)
- **المصدر المعتمد:** مجلد `standards/` هو المصدر المركزي المعتمد والنهائي.
- **المسودات:** مجلد `drafts/` غير معياري ولا يُستخدم كمرجع تنفيذ بأي شكل من الأشكال. يمنع نسخ محتوى `drafts/AGENTS.md` أو قواعد مشروع مصدر منه.
- **نقطة الانطلاق:** يجب بدء أي مهمة من حالة `main` الفعلية دائمًا، ويجب قراءة root `AGENTS.md` قبل التخطيط.
- **Git Staging:** استخدم staging لمسارات صريحة فقط (مثال: `git add path/to/file`). يُمنع منعًا باتًا استخدام `git add .` أو `git add -A`.
- **Git History:** يُمنع `git commit --amend` وأي force-push. أي تصحيح يكون Commit جديدة مستقلة.
- **نطاق المعايير:** لا تُعدّل معيارًا معتمدًا أو توسع نطاقه بدون قرار صريح من المالك.
- **عزل السياق:** لا تخلط قواعد أو سياق أو معلومات من مشاريع أخرى داخل هذه الريبو. هذا المستودع منعزل وخاص بالمعايير الهندسية الخاصة به فقط.
- **تصحيحات PR:** عند وجود تصحيح لعمل Jules على PR مفتوحة، يتم التصحيح عبر Reply داخل نفس PR بمنشن صريح لـ `@jules`، ولا تُفتح Session جديدة لتصحيحات نفس PR.
- **اعتماد الدمج:** المالك هو صاحب قرار الدمج النهائي واعتماد أو تغيير المعايير.
